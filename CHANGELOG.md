# Changelog

## 0.1.0

* First release.
* Eclipse now goes up to 16. Eclipse 9–16 keep all eight Eclipse modifiers and add Karma 1–8, locked for the whole run.
* Eclipse 1–8 no longer include Karma.
* Eclipse menu: medals for 9–16, a Karma box with hoverable descriptions, a wider layout, and Escape to go back.
* Eclipse 9–16 have their own badges in character select and during the run.
